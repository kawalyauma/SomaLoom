## SO THAT AND IN ORDER TO

### Learning objectives
- Explain the meaning of so that and in order to.
- Recognise and use the correct sentence patterns.
- Write clear and correct sentences in this lesson.

### Meaning
We use so that and in order to to explain the purpose of an action.

### Important rules
- So that often introduces a new clause with a subject and can/will/may.
- In order to is followed by the base verb.
- Both explain why someone does something, but their sentence patterns differ.

### Examples
1. We study so that we can pass.
2. Amina reads so that she can improve.
3. We left early in order to arrive on time.
4. Musa saved money in order to buy a book.
5. The teacher speaks loudly so that all can hear.
6. I washed my hands in order to stay clean.

### Worked example
**Question:** Join: We carried umbrellas. We wanted to stay dry. (so that)

**Answer:** We carried umbrellas so that we could stay dry.

### Common mistakes

| Incorrect | Correct |
|---|---|
| We study in order to we pass. | We study in order to pass. |
| She left early so that arrive. | She left early so that she could arrive. |
| He ran in order to winning. | He ran in order to win. |
| We read so that to learn. | We read so that we can learn. |
