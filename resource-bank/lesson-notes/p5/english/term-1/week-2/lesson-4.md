## CONDITIONAL SENTENCES: THE FIRST CONDITIONAL (IF1)
**Topic:** Conditional sentences

### What you will learn
By the end of this lesson, you should be able to:
1. Recognise the **if-clause** and the **main clause**.
2. Identify the verb forms used in a first conditional sentence.
3. Construct correct sentences about possible future events.
4. Use commas correctly when the if-clause comes first.

### 1. Meaning
A **conditional sentence** tells us what may happen if a condition is met.

We use the **first conditional (IF1)** to talk about something that may really happen in the future.

**Example:** If it rains, we will stay indoors.

The rain is possible. Staying indoors is what we will do if it rains.

### 2. The two parts of IF1
A first conditional sentence normally has two clauses:

| Clause | Meaning | Example |
|---|---|---|
| If-clause | States the condition | If we study hard |
| Main clause | States the likely result | we will pass the test. |

Put them together:
**If we study hard, we will pass the test.**

### 3. How to form IF1

**If + subject + present simple, subject + will + base verb.**

- If Amina **wakes** early, she **will catch** the school bus.
- If the farmer **waters** the seedlings, they **will grow**.
- If we **leave** now, we **will arrive** on time.
- If I **finish** my work, I **will help** my mother.

**Important:** In the if-clause, use the **present simple**, not *will*.

**Correct:** If the sun **shines**, we will play outside.

**Incorrect:** If the sun **will shine**, we will play outside.

### 4. Changing the order of clauses
We can put the main clause first without changing the meaning.

- **If** you practise daily, you will improve your handwriting.
- You will improve your handwriting **if** you practise daily.

**Punctuation:** Put a comma after the if-clause when it comes first. Usually, do not put a comma before *if* when it comes second.

### 5. Affirmative and negative forms
The condition or result may be negative.

- If we **do not hurry**, we **will miss** the bus.
- If Musa **does not revise**, he **will not do** well in the test.
- If you **eat** the ripe mango, you **will not be** hungry.

**Short forms:** *do not = don't; does not = doesn't; will not = won't.*

### 6. Asking questions
We can ask about a possible result.

- **What will happen if it rains?** We will remain inside.
- **Will you visit the library if you finish your homework?** Yes, I will.
- **What will Sarah do if she finds the lost book?** She will return it.

### 7. Common mistakes and corrections

| Incorrect | Correct |
|---|---|
| If it will rain, we will stay indoors. | If it rains, we will stay indoors. |
| If she study, she will pass. | If she studies, she will pass. |
| If I arrive late I will apologise. | If I arrive late, I will apologise. |
| If you heat ice, it will melts. | If you heat ice, it will melt. |
| We will be happy if we will win. | We will be happy if we win. |

### 8. Worked examples
**Example A. Complete:** If I ______ (see) the head teacher, I will greet her.

Use the present simple after *if*.

**Answer:** If I **see** the head teacher, I will greet her.

**Example B. Join the sentences:** You will get wet. You do not carry an umbrella.

Make the condition the if-clause.

**Answer:** If you **do not carry an umbrella**, you **will get wet**.

**Example C. Begin with 'We will':** If we practise, we will win the match.

**Answer:** We will win the match if we practise.

### Remember
- The **if-clause** states the condition; the **main clause** states the result.
- In IF1, use **if + present simple** and **will + base verb**.
- Do **not** put *will* in the ordinary first-conditional if-clause.
- Put a comma after the if-clause when it comes first.
