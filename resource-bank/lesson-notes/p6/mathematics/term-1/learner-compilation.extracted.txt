Primary Six Mathematics | Term 1 | Week 1 | Lesson 1: Types
of Sets
What you will learn
• Recognise equal, unequal, equivalent and non-equivalent sets.
• Match elements of two sets correctly.

What is a set?
• A set is a well-defined collection of objects or numbers. The objects are called elements or members.
• Use curly brackets to list elements. For example, A = {2, 4, 6}. The number of elements is written
n(A) = 3.
• Order does not matter in a set. Repeating an element does not increase the number of elements.

Equal and unequal sets
• Two sets are equal when they contain exactly the same elements. A = {1, 3, 5} and B = {5, 1, 3} are
equal: A = B.
• Two sets are unequal if at least one element differs. C = {1, 3, 5} and D = {1, 3, 7} are unequal: C ≠
D.

Equivalent and non-equivalent sets
• Equivalent sets have the same number of distinct elements, even if the elements differ. E = {a, b, c}
and F = {7, 8, 9} are equivalent because n(E) = n(F) = 3.
• Non-equivalent sets have different numbers of elements. G = {2, 4} and H = {p, q, r} are
non-equivalent because 2 ≠ 3.

Matching sets
• Draw a line or an arrow from each element in one set to one element of another. This is one-to-one
matching when no element is left over or matched twice.
• Example: {cup, plate, spoon} can match {1, 2, 3} in three one-to-one pairs.

Intersecting, Disjoint, Union and Universal Sets
What you will learn
• Identify the intersection and union of two sets.
• Recognise disjoint and intersecting sets.
• Explain a universal set using a clear example.

Universal set (rectangle)

• The intersection A ∩ B contains elements found in both A and B.
• Example: A = {1, 2, 3, 4} and B = {3, 4, 5}. Then A ∩ B = {3, 4}.
• Sets with at least one common element are intersecting (or joint) sets.

Disjoint sets
• Disjoint sets have no common elements. Their intersection is the empty set, written ∅.
• Example: C = {2, 4, 6} and D = {1, 3, 5}. Then C ∩ D = ∅.

Union of sets
• The union A ∪ B contains all elements from A or B or both. List each element only once.
• For A = {1, 2, 3, 4} and B = {3, 4, 5}, A ∪ B = {1, 2, 3, 4, 5}.

Universal set
• The universal set, U, contains all elements being considered in a question.
• If we study whole numbers from 1 to 6, U = {1, 2, 3, 4, 5, 6}. A set in this question must use members
from U.

Worked examples
1. Find {a, b, c} ∩ {b, d}. The only common member is b. Answer: {b}.
2. Find {1, 3} ∪ {3, 5, 7}. {1, 3, 5, 7}; write 3 only once.
3. Are {2, 6} and {1, 5} disjoint? Yes. They share no elements.

Difference and Complement of Sets
What you will learn
• Find the difference between two sets.
• Find the complement of a set relative to a stated universal set.
• Identify the correct Venn diagram regions.

Difference of sets
• A − B means elements in A but not in B.
• If A = {1, 2, 3, 4} and B = {3, 4, 5}, then A − B = {1, 2}.
• B − A = {5}. Notice that A − B is usually different from B − A.

Complement
• The complement of A, written A′, contains elements in the universal set U that are not in A.
• If U = {1, 2, 3, 4, 5, 6} and A = {2, 4, 6}, then A′ = {1, 3, 5}.
• Always write or check the universal set before finding a complement.

Shading a Venn diagram
• To shade A ∩ B, shade only the overlap.
• To shade A ∪ B, shade both circles including the overlap.
• To shade A − B, shade the part of circle A outside circle B.
• To shade A′, shade the region inside U but outside circle A.

Primary Six Mathematics | Term 1 | Week 1 | Lesson 4:
Subsets and the Number of Subsets
What you will learn
• Identify subsets and proper subsets.
• List the subsets of a small set.
• Find the number of subsets and proper subsets.

Subset
• A is a subset of B, written A ⊆ B, when every element of A belongs to B.
• Example: {2, 4} ⊆ {2, 4, 6}. Every set is a subset of itself.
• The empty set ∅ is a subset of every set.

Proper subset
• A proper subset contains some but not all elements of the original set. Write A ⊂ B when A is a proper
subset of B.
• Example: {2, 4} ⊂ {2, 4, 6}, but {2, 4, 6} is not a proper subset of itself.

Listing subsets
• Let A = {a, b}. Its subsets are ∅, {a}, {b}, {a, b}.
• The proper subsets of A are ∅, {a}, {b}.

Counting subsets
• If a set has n distinct elements, the total number of subsets is 2ⁿ.
• The number of proper subsets is 2ⁿ − 1.

Primary Six Mathematics | Term 1 | Week 1 | Lesson 5:
Finding the Number of Elements in Sets
What you will learn
• Count distinct elements in a set.
• Use n(A) for the number of elements.
• Find the number of elements in a union, including overlap.

Counting elements
• The number of distinct elements in set A is written n(A).
• If A = {2, 4, 6, 8}, n(A) = 4. Repeated items are counted once: n({a, a, b}) = 2.
• An empty set has no elements: n(∅) = 0.

Elements in a Venn diagram

A

A only

B

A∩B

B only

Universal set (rectangle)

• A Venn diagram uses a circle for each set within a rectangle for the universal set.
• When circles overlap, the common members are placed only in the overlap. Do not count them twice.

Counting a union
• For two finite sets: n(A ∪ B) = n(A) + n(B) − n(A ∩ B).
• Example: n(A) = 9, n(B) = 7 and n(A ∩ B) = 3. Then n(A ∪ B) = 9 + 7 − 3 = 13.
• If A and B are disjoint, n(A ∩ B) = 0, so n(A ∪ B) = n(A) + n(B).

Counting regions
• Number in A only = n(A) − n(A ∩ B).
• Number in B only = n(B) − n(A ∩ B).
• Number outside both = total in U − n(A ∪ B), if U is given.

Worked examples
1. Find n({1, 2, 2, 3, 4, 4}). There are four distinct elements: 1, 2, 3, 4. So n(A) = 4.
2. n(A)=12, n(B)=10, n(A ∩ B)=4. Find n(A ∪ B). 12 + 10 − 4 = 18.
3. A class has 30 pupils; 18 like football, 13 like netball and 6 like both. How many like neither? At least
one = 18 + 13 − 6 = 25. Neither = 30 − 25 = 5.

Practice
1. Find n({2, 3, 5, 7, 11}).
2. Find n({a, a, b, c, c}).
3. Find n(∅).
4. If n(A)=8, n(B)=6 and n(A ∩ B)=2, find n(A ∪ B).
5. If n(P)=15 and n(P ∩ Q)=4, find the number in P only.
6. A class has 40 pupils. 22 like mangoes, 19 like bananas and 8 like both. How many like at least one?
7. Using Question 6, how many like neither?
8. Two disjoint sets have 7 and 9 members. Find the number in their union.

Learn and understand
A cube is a number multiplied by itself three times. The cube root undoes cubing. For example, 43=64
and ∛64=4.

Worked examples
Example 1: Find 53.
Working: 5×5×5=125.
Example 2: Find ∛216.
Working: 63=216, so ∛216=6.

Learn and understand
A sequence is an ordered list that follows a rule. Identify the rule and use it to find the missing or next
terms.

Worked examples
Example 1: Find the next two terms: 5,10,20,40,...
Working: Multiply by 2: 80,160.
Example 2: Fill 2,6,12,20,___.
Working: Differences 4,6,8, so next difference 10: 30.

Primary Six Mathematics — Number puzzles and magic
squares
Name: ____________________ Date: __________

Learn and understand
A 3×3 magic square uses each number 1–9 once. Every row, column and diagonal has sum 15. Use
arithmetic and checking to fill blanks.

Worked examples
Example 1: Find missing entry in a row: 8,1,__ where sum is 15.
Working: 15−8−1=6.
Example 2: Why is 5 in the centre of the usual 1–9 magic square?
Working: The middle entry balances the rows and diagonals; the standard arrangement has 5 at the
centre.
