# Integration decisions

2026-10-26. Original PRs #9–#16 are preserved through explicit integration merges. Main remains cae1013; no force pushes, original PR merges or automatic Actions triggers. PR #15 reused the exact foundation history; only 15 feature files were added after #9.

1. Central API composition owns router registration. Removed test-side registration so tests exercise the shipped application. Central error/request-ID, HttpOnly sessions, school roles and composite tenant FKs remain authoritative. Added allowed browser mutation methods, never bypassed Origin checks.
2. Migrations: foundation remains immutable. Revision 06a413e11f8b snapshots reviewed metadata from ingestion, curriculum/knowledge, extraction outbox/receipts and assessment proposals. Fixed conflicting constraint/index names. PostgreSQL 16/pgvector is the acceptance database; SQLite remains supplementary. Downgrade drops new feature tables; production rollback uses backup/roll-forward.
3. EBS is the default durable store, consistent with the original design. SOMALOOM_STORAGE_BUCKET/SOMALOOM_KMS_KEY_ID optionally select shared S3 across every pipeline stage; old ingestion variable names remain compatible. Production scanning stays mandatory.
4. resource.available uses event_type from Agent 2. Consumer validates the persisted outbox payload and IDs, creates a durable extraction claim/receipt and ACKs only after enqueue. Duplicate resource/version/engine claims are unique. Dispatcher recovers persisted intent and reports heartbeat. Invalid stream entries stay pending with sanitized logs.
5. Extraction preserves native source blocks and immutable normalized JSON. Text/plain is supported; website imports preserve original HTML rather than losing structure. Indexing omits uncertain normalized blocks and unreviewed visuals. Original sources and equation crops remain for review.
6. Topics are not outcome IDs. Approved curriculum mappings feed Agent 4 research and current rights-checked snippets; stable evidence rows link real content blocks and outcomes before generation. Missing sources fail closed. Semantic retrieval is optional and explicitly reports keyword mode without a configured 1536-dimensional embedding provider.
7. TeachingStudio and assessment validators execute inside Agent 5's bounded job framework. Canonical publishing blocks have stable IDs, type, rows, citations and evidence_ids; typed original teaching/assessment payloads remain in body metadata. Invalid family output fails rather than silently publishing generic text.
8. No automatic teacher approval. Reviews belong to immutable versions; saving creates a new unapproved version. Publishing requires attestations and revalidates source rights. A document-row lock serializes revisions.
9. Visual bytes resolve only from current school-owned, explicitly reviewed assets. No arbitrary URLs/file paths. PDF and DOCX support reviewed diagrams/maps/images; DOCX math is native OMML. Teacher answers use separate blocks and are removed from student exports; marking-guide-only documents cannot export as students.
10. Codex CLI 0.164.0 help was inspected without calling inference. Official CLI docs confirm structured output; use output-schema plus output-last-message. The app requires an operator-provisioned isolated runner and dedicated credential. This agent's personal login is never copied or exposed. API fallback is independent and remains credential-gated.
11. AWS staging is a new instance with no ingress, IMDSv2/hop=1, encrypted disks, dedicated IAM and private versioned KMS S3. Initial t3.large launch was rejected by the account's Free Tier restriction; reused the same provisioned resources and selected eligible m7i-flex.large (8 GiB). Existing mobile/production instances were not modified. No public launch is authorized by a successful private smoke test.

Official CLI reference: https://developers.openai.com/codex/cli/reference/

12. Final review tightened curriculum execution context: research attribution uses the actual authenticated generation requester, and supplied class/subject IDs must match the selected topic's stable catalogue IDs. A malicious or mistaken class/subject cannot silently relabel a topic. Six-family native tests now submit as a teacher and verify research requester attribution; wrong-context denial is exercised.

13. Extraction workers lock and claim the persisted job before processing; duplicate running submissions return the current state. This complements the resource-version uniqueness constraint and durable event receipts.
