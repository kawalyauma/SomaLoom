# Lesson, week and term PDFs and browser-generated images

Open `/publish` (PDF downloads) or use Download PDF in a saved document's editor. Select class, subject, term and lesson/week/term. Learner editions omit answer keys, evidence IDs, source/audit sections and teacher-only/process notes. Worked teaching examples remain. Teacher editions retain staff material. Private staff drafts have a review label; final PDFs still require educator approval for every selected latest revision. Selecting a term with missing source-scheme slots returns a missing-lesson message, never a misleading partial term book.

PDF layout is A4 with embedded readable fonts, wrapped tables/repeated headers, typeset equations, page numbers, chapter bookmarks and contents for multi-chapter books. A weekly book starts its content on the first page instead of wasting a cover sheet. Missing visuals and unresolved lesson mappings fail preflight. No AI inference runs in the export path.

`GET /api/v1/exports/catalog` returns the authenticated school's source-backed schedules and existing lesson-note document coverage. Deleted/stale scheme sources are excluded. `POST /api/v1/exports/scoped-pdf` accepts `grade`, `subject`, `term`, optional `week`, optional `lesson`, `edition` (`draft` or `approved`) and `audience` (`student` or `teacher`). It returns the PDF bytes with a descriptive filename. A lesson requires a week. Newer specific lesson documents are preferred over weekly documents; revisions are loaded at download time. Lesson extraction uses outcome IDs, not guessed section order; combined teaching blocks must be split by the browser agent before individual download. Shared supplementary directions are omitted and explicitly relevant images can be reused. Saving/importing a resource is distinct from approval/publication.

## Image coordinator contract

The existing NotesUG server agent remains the single coordinator. Educational prose, questions, keys and new image content come from regular ChatGPT in the existing server Chrome profile, not Codex-authored resources or an image-generation API. The owner-authorized continuous coordinator reads its mission/checkpoints under `/opt/codex-mobile/automation/p5-p6` on the agent server.

- New imported lesson documents automatically queue `visual_needed` blocks. Existing documents can be scanned with `POST /api/v1/image-requests/from-document/{document_id}`. Repeating the scan reuses the same document/block requests.
- `GET /api/v1/image-requests?status=prompt_ready` returns pending prompts. The image metadata includes `document_id`, exact `block_id`, `document_version_id`, `outcome_ids`, description and transport. Other supported list states: `generating`, `waiting`, `failed`, `imported`.
- Before/after a browser submission, `POST /api/v1/image-requests/{id}/progress` records `status`, optional `chat_url` (regular ChatGPT conversation), `error` and UTC `next_retry_at`. Retain the chat link and recover an active response instead of duplicating generation. This endpoint cannot falsely mark an image imported.
- Obtain the actual generated file through the server browser's documented controls. Verify proportions, labels and mathematical/scientific details. Original diagram SVGs produced by ChatGPT may be safely rasterized after inspection; do not use unsafe SVG scripts/external resources or invent replacement content in Codex.
- Upload PNG/JPEG/WebP with multipart `POST /api/v1/image-requests/{id}/import` (`file`, optional `credit`). Existing validation enforces image formats, 10 MB and 15 MP, removes extraneous encoding metadata and stores an immutable hash-specific asset.
- `POST /api/v1/image-requests/{id}/attach` accepts `document_id` and optional `block_id`; queued requests default to their stored block. It replaces that placeholder in a new saved version, preserving its ID, outcome IDs and citations. Repeating the same attachment does not create duplicate revisions. A changed/missing placeholder or foreign document returns a conflict. Legacy manual append remains available for manually created requests.

Provenance stays in the image/audit record. Learner PDFs print the educational caption; teacher editions can show attribution. Image attachment does not fabricate educator approval. Image progress and results appear in Image workspace, refreshing every ten seconds. Authentication/captcha and quota waits must be checkpointed; never weaken browser protections to bypass them.

## Validation

Scoped PDF tests cover real tenant fixtures for lesson/week/term assembly, current source schedules, missing slots, approval gating and cross-school isolation; output checks cover contents/bookmarks, first-page content and learner/teacher separation. Image tests cover idempotent queueing, exact placeholder replacement, preserved outcome mapping and cross-school rejection. The live P6 Mathematics Term3 Week1 book was retrieved through the HTTPS API with three imported diagrams. Term3 coverage remains incomplete; the source-backed catalog reports that explicitly.
